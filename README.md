# Image Gallery

A simple and responsive image gallery built with HTML, CSS, and JavaScript.

## Features
- Next/previous image navigation
- Hover effects and smooth transitions
- Mobile-friendly responsive layout
- Bonus category filters: All, Nature, City, Tech, and Travel
- Local image support from the images folder

## How to Run
1. Open the project folder in a browser, or
2. Start a simple local server from this folder and open the page.

Example:
```bash
python -m http.server 8000
```
Then open:
```text
http://127.0.0.1:8000/index.html
```
